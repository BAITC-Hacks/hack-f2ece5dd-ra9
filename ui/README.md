# UI Протокол

Самостоятельный интерфейс совещаний и поручений. Этот коммит изменяет только папку ui/. Код сервера, модели, анализатор, корневые настройки и скрипты запуска не изменяются.

## Запуск интерфейса

Можно использовать существующий сервер проекта, если он обслуживает ui/. Для отдельного показа без backend:

```powershell
python -m http.server 8767 --bind 127.0.0.1 --directory ui
```

Откройте http://127.0.0.1:8767 и нажмите «Открыть пример» или «Показать весь сценарий». Порт выбран отдельно от уже запущенного приложения на 8766. file:// не поддерживается из-за ES-модулей.

Runtime-зависимости, npm install и сборка не нужны. ui/package.json задаёт модульный режим только для тестов frontend и не меняет настройки backend.

При статическом запуске /api недоступен: это ожидаемо. Интерфейс позволяет демонстрировать готовый пример, редактировать результаты, сохранять историю в IndexedDB, слушать выбранное аудио и экспортировать DOCX/TXT/JSON. Распознавание аудио отключено. JSON с массивами segments и tasks импортируется без сервера; импорт только segments требует /api/analyze.

## Для дальнейшей интеграции

Сохранены экран «Поручения», его редактор, отдельные отметки проверки/выполнения и связь с транскриптом. Точки интеграции и правила данных описаны в INTEGRATION.md. Backend в этом коммите не реализуется и не переписывается.

## Проверки frontend

```powershell
node --test ui/tests/domain.test.mjs
```

Дополнительный браузерный тест требует доступного Playwright как инструмента разработки и запущенного UI. По умолчанию используется установленный Chrome на Windows; путь можно указать через BROWSER_PATH.

```powershell
$env:TEST_URL = "http://127.0.0.1:8767"
$env:BROWSER_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
node ui/tests/e2e.cjs
```

API в этом браузерном тесте явно подменён тестовыми ответами: он проверяет клиентский адаптер, ошибки, этапы, повторную попытку, частичный результат, перемотку и отказ сохранения. Реальная совместимость с будущим backend пока не проверена.

DOCX — настоящий OOXML/ZIP с исправленными данными. Структура проверена; визуальный рендер в Word/LibreOffice перед показом рекомендуется проверить отдельно. История привязана к браузеру и origin; JSON-копия не включает аудио.
